How to Publish on GitHub Pages

Host this entire travel planner online for free in under 2 minutes.

1
Create a new repository on GitHub

Go to github.com/new and name your repository (e.g., tripcraft-planner).

2
Upload this file as index.html

Save this webpage file as index.html and upload it directly to the root directory of your repository.

3
Enable GitHub Pages

In your repo, navigate to Settings ➔ Pages. Under Build and deployment, set Source to Deploy from a branch, pick the main branch, and click Save.
